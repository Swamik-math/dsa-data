# Node.js Backend Learning Repository

A comprehensive, structured learning path for Node.js backend development — from absolute basics to building real REST APIs.

## 🎯 Who Is This For?

Anyone who wants to learn backend development with Node.js, starting from JavaScript fundamentals and progressing through HTTP servers, Express.js, REST APIs, and databases.

## 🗺️ Learning Path Overview

| Phase | Topic | Duration |
|-------|-------|----------|
| [Phase 1](./phase-1-fundamentals/) | JavaScript & Node.js Fundamentals | Week 1-2 |
| [Phase 2](./phase-2-http-servers/) | HTTP Servers (no frameworks) | Week 2-3 |
| [Phase 3](./phase-3-express-basics/) | Express.js Framework | Week 3-4 |
| [Phase 4](./phase-4-rest-apis/) | Building REST APIs | Week 4-5 |
| [Phase 5](./phase-5-databases/) | Database Integration | Week 5-6 |

## 🚀 Getting Started

### Prerequisites
- Install [Node.js](https://nodejs.org) (v18 or later recommended)
- Install a code editor ([VS Code](https://code.visualstudio.com/) recommended)
- Basic familiarity with the terminal/command line

### Setup

```bash
# Install dependencies
npm install

# Run any example file
node phase-1-fundamentals/01-variables-and-functions.js
```

## 📚 Phase Breakdown

### Phase 1 — Fundamentals
Learn JavaScript and Node.js core concepts:
- Variables, types, functions, and arrow functions
- Objects and arrays
- Callbacks, Promises, and async/await
- Module system (require / module.exports)
- npm and package.json
- File system operations (fs module)

Start here: [phase-1-fundamentals/](./phase-1-fundamentals/)

### Phase 2 — HTTP Servers
Build servers without any framework:
- What HTTP is and how it works
- Creating HTTP servers with Node's built-in http module
- HTTP methods (GET, POST, PUT, DELETE)
- Status codes and their meanings
- Headers and routing from scratch

[phase-2-http-servers/](./phase-2-http-servers/)

### Phase 3 — Express.js
Use the most popular Node.js web framework:
- Setting up Express
- Middleware concept and custom middleware
- Express routing
- Serving static files
- Request/response handling
- Error handling patterns

[phase-3-express-basics/](./phase-3-express-basics/)

### Phase 4 — REST APIs
Build production-style REST APIs:
- REST principles and best practices
- API endpoint design
- Complete CRUD API
- Input validation
- Proper JSON response formatting

[phase-4-rest-apis/](./phase-4-rest-apis/)

### Phase 5 — Databases
Connect your APIs to real databases:
- SQL vs NoSQL comparison
- SQLite for quick local development
- MongoDB basics
- CRUD operations with a database

[phase-5-databases/](./phase-5-databases/)

## Tips for Success

- **Run every example** — don't just read the code
- **Complete the exercises** — practice is how you learn
- **Build the projects** — apply your knowledge to real things
- **Read error messages** — they tell you exactly what's wrong
- **Use console.log** liberally while learning
