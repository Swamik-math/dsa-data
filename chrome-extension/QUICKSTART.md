# Quick Start Guide - Auto Scroll & Skip Videos

Get up and running in 2 minutes!

## 1️⃣ Load the Extension

1. Open Chrome and go to: **`chrome://extensions/`**
2. Turn ON **"Developer mode"** (toggle in top-right corner)
3. Click **"Load unpacked"**
4. Select your extension folder
5. Done! ✅

You should see the extension icon in your Chrome toolbar.

## 2️⃣ Test It

1. Go to any site with pagination (e.g., a news site with multiple pages)
2. Click the extension icon
3. Click **"Start"** button
4. Watch it scroll and navigate automatically!
5. Click **"Stop"** to pause

## 3️⃣ Customize (Optional)

1. Click **"Options"** button in the popup
2. Adjust:
   - Scroll speed (how fast it scrolls)
   - Video skip method (skip to end or speed up)
   - Custom selector if needed
3. Click **"Save Settings"**

## Key Features

| Feature | What it does |
|---------|-------------|
| **Auto Scroll** | Smoothly scrolls to bottom of page |
| **Video Skip** | Automatically skips embedded videos |
| **Auto Navigate** | Finds and clicks the "Next" button |
| **Loop** | Repeats until no more pages |

## Troubleshooting

**Not finding next button?**
→ Use custom selector in Options

**Videos not skipping?**
→ Try different skip method in Options

**Extension not running?**
→ Refresh the page first (F5)

**Need to reload settings?**
→ Toggle extension off/on in `chrome://extensions`
