📋 Default Next Button Selectors
The extension searches for next buttons using these patterns (in order):

• aria-label attributes containing "next"
• Element text containing "Next", "next", ">", "Load More"
• Class names containing "next"
• href attributes with pagination parameters
• data-testid attributes

If none are found, the automation stops.
